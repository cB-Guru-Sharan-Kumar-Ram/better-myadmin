Developers Information
======================

BetterMyAdmin is free software (GPL-2.0-or-later), so you're invited to
contribute to it. The code and the developer documentation live in the
`BetterMyAdmin repository <https://github.com/cB-Sigma/better-myadmin>`_;
its :file:`docs/` folder is the place to start:

* `Documentation index
  <https://github.com/cB-Sigma/better-myadmin/blob/main/docs/README.md>`_
  and `vision and principles
  <https://github.com/cB-Sigma/better-myadmin/blob/main/docs/00-vision-and-principles.md>`_;
* `Development setup
  <https://github.com/cB-Sigma/better-myadmin/blob/main/docs/architecture/14-development-setup.md>`_:
  getting a development environment, common commands and the feature workflow;
* `Architecture
  <https://github.com/cB-Sigma/better-myadmin/tree/main/docs/architecture>`_:
  the tech stack, the server and the web application, the API, the data model,
  security and performance;
* `Parity exceptions
  <https://github.com/cB-Sigma/better-myadmin/blob/main/docs/reference/parity-exceptions.md>`_:
  every intentional difference from phpMyAdmin, with its rationale;
* `Configuration directive reference
  <https://github.com/cB-Sigma/better-myadmin/blob/main/docs/reference/config-directives.md>`_.

Bugs and feature requests go to the repository's
`issue tracker <https://github.com/cB-Sigma/better-myadmin/issues>`_.
