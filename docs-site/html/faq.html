FAQ - Frequently Asked Questions

BetterMyAdmin keeps phpMyAdmin’s features and interface, so phpMyAdmin’s Link section (books, tutorials) is useful for in-depth coverage too. The questions below are phpMyAdmin’s, with their numbers; those about PHP or a web server are kept with a short answer saying why they do not apply to BetterMyAdmin.

Server

1.1 My server is crashing each time a specific action is required or phpMyAdmin sends a blank page or a page full of cryptic characters to my browser, what can I do?

BetterMyAdmin does not run on PHP or in a web server: it is a single Node.js process (or the Docker image) with its own HTTP server. The directives this answer was about ($cfg['OBGzip'] and PHP’s zlib.output_compression) do not exist there.

If BetterMyAdmin shows a blank page, look at the server’s error output (docker logs for the image) and at the browser’s JavaScript console (see 5.19 I get JavaScript errors in my browser.).

1.2 My Apache server crashes when using phpMyAdmin.

BetterMyAdmin does not run on PHP or in a web server: it is a single Node.js process (or the Docker image) with its own HTTP server. If you run Apache as a reverse proxy in front of it, a crash of Apache is not related to BetterMyAdmin.

1.7 How can I gzip a dump or a CSV export? It does not seem to work.

Compression is built into BetterMyAdmin: zip and gzip exports need no extra software and no PHP Zlib support. Check that $cfg['ZipDump'] and $cfg['GZipDump'] are not disabled.

1.8 I cannot insert a text file in a table, and I get an error about safe mode being in effect.

BetterMyAdmin does not run on PHP, so PHP’s safe mode and upload_tmp_dir do not apply. An uploaded file is staged in a private bma-import subdirectory of the system temporary directory (mode 0700), which needs no setup.

1.10 I’m having troubles when uploading files with phpMyAdmin running on a secure server. My browser is Internet Explorer and I’m using the Apache server.

BetterMyAdmin does not run on PHP or in a web server: it is a single Node.js process (or the Docker image) with its own HTTP server. This Internet Explorer and Apache SSL workaround does not apply.

1.11 I get an ‘open_basedir restriction’ while uploading a file from the import tab.

BetterMyAdmin does not run on PHP, so there is no open_basedir restriction and $cfg['TempDir'] is not needed for uploads: an uploaded file is staged in a private subdirectory of the system temporary directory.

1.12 I have lost my MySQL root password, what can I do?

BetterMyAdmin does authenticate against MySQL server you’re using, so to recover from BetterMyAdmin password loss, you need to recover at MySQL level.

The MySQL manual explains how to reset the permissions.

If you are using MySQL server installed by your hosting provider, please contact their support to recover the password for you.

1.15 I have problems with mysql.user column names.

1.16 I cannot upload big dump files (memory, HTTP or timeout problems).

BetterMyAdmin reads imports in chunks and streams exports, so memory is not a concern, but some limits apply:

  • $cfg['MaxUploadSize'] limits the size of an uploaded file (512 MiB by default; the Docker variable UPLOAD_LIMIT sets it). It takes the place of PHP’s upload_max_filesize and post_max_size, which do not exist in BetterMyAdmin.

  • $cfg['ExecTimeLimit'] limits how long an import runs (300 seconds by default; 0 for no limit; the Docker variable MAX_EXECUTION_TIME sets it). With “Allow interruption”, an import that reaches the limit can be resumed.

  • $cfg['Import']['MaxDecompressedSize'] limits what a compressed file may decompress to (ten times the upload limit by default).

  • A reverse proxy in front of BetterMyAdmin may have its own limit on the size of a request or on its duration.

There exist several workarounds if your upload is still too big:

  • Look at the $cfg['UploadDir'] feature. This allows one to upload a file to the server via scp, FTP, or your favorite file transfer method (or to mount it into the Docker container, see PMA_UPLOADDIR). BetterMyAdmin is then able to import the files from that directory, without the upload limit. More information is available in the Configuration of this document.

  • Using a utility (such as BigDump) to split the files before uploading. We cannot support this or any third party applications, but are aware of users having success with it.

  • If you have shell (command line) access, use MySQL to import the files directly. You can do this by issuing the “source” command from within MySQL:

    source filename.sql;

1.17 Which Database versions does BetterMyAdmin support?

For MySQL, versions 5.5 and newer are supported.

For MariaDB, versions 5.5 and newer are supported.

BetterMyAdmin is checked against MySQL 8.0 and 8.4 and MariaDB 10.11 and 11.4. The minimum is $cfg['MysqlMinVersion'], as in phpMyAdmin.

1.17a I cannot connect to the MySQL server. It always returns the error message, “Client does not support authentication protocol requested by server; consider upgrading MySQL client”

BetterMyAdmin does not use PHP’s MySQL client library: it connects with the mysql2 Node.js driver, which supports the mysql_native_password, caching_sha2_password, sha256_password and mysql_clear_password authentication methods. If the server asks for another method, change the account to one of these. More information is located in the MySQL Documentation.

1.20 I receive an error about missing mysqli and mysql extensions.

BetterMyAdmin does not run on PHP and needs no PHP MySQL extension: it connects with the built-in mysql2 Node.js driver.

1.21 I am running the CGI version of PHP under Unix, and I cannot log in using cookie auth.

1.22 I don’t see the “Location of text file” field, so I cannot upload.

1.23 I’m running MySQL on a Win32 machine. Each time I create a new table the table and column names are changed to lowercase!

This happens because the MySQL directive lower_case_table_names defaults to 1 (ON) in the Win32 version of MySQL. You can change this behavior by simply changing the directive to 0 (OFF): Just edit your my.ini file that should be located in your Windows directory and add the following line to the group [mysqld]:

set-variable = lower_case_table_names=0

Note

Forcing this variable to 0 with –lower-case-table-names=0 on a case-insensitive filesystem and access MyISAM tablenames using different lettercases, index corruption may result.

Next, save the file and restart the MySQL service. You can always check the value of this directive using the query

SHOW VARIABLES LIKE 'lower_case_table_names';

See also

Identifier Case Sensitivity in the MySQL Reference Manual

1.32 Can I use HTTP authentication with IIS?

1.34 Can I directly access a database or table pages?

Yes. Every page of BetterMyAdmin has its own URL, which you can bookmark or link to, for example:

  • https://example.com/s/1/ – the home page of server 1;

  • https://example.com/s/1/db/sakila/ – a database;

  • https://example.com/s/1/db/sakila/t/actor/browse – a table’s Browse tab.

The number after /s/ is the server number (its position in the $cfg['Servers'] list, from 1).

phpMyAdmin’s addresses keep working: index.php?route=/database/structure&db=sakila&server=1 and phpMyAdmin 4’s per-page scripts (db_structure.php?db=sakila) are redirected to the BetterMyAdmin page they name. No rewrite rules are needed.

BetterMyAdmin does not run on PHP or in a web server: it is a single Node.js process (or the Docker image) with its own HTTP server. Apache’s CGI is not involved. If a reverse proxy is in front of BetterMyAdmin, it must pass the Authorization header through (see HTTP authentication mode).

1.36 I get an error “500 Internal Server Error”.

1.37 I run BetterMyAdmin on cluster of different machines and password encryption in cookie auth doesn’t work.

BetterMyAdmin does not encrypt the password into the cookie: the credentials stay in the session store of the instance the user logged in to, in its $cfg['DataDir']. When several instances run behind a load balancer, send each user to the same instance (sticky sessions), and give every instance the same $cfg['blowfish_secret'].

1.39 When I try to connect via https, I can log in, but then my connection is redirected back to http. What can cause this behavior?

This happens when BetterMyAdmin does not know that the site is accessed with https, typically behind a reverse proxy that terminates TLS. Make the proxy send an X-Forwarded-Proto: https header (and keep the Host header), or set $cfg['PmaAbsoluteUri'] to the public https URL. $cfg['ForceSSL'] additionally redirects plain HTTP requests to https.

1.40 When accessing BetterMyAdmin via an Apache reverse proxy, cookie login does not work.

BetterMyAdmin’s cookies are scoped to the path in $cfg['Listen']['basePath'] (/ by default). If the reverse proxy publishes BetterMyAdmin under another path or host, either set $cfg['Listen']['basePath'] and $cfg['PmaAbsoluteUri'] to the public path and URL, or make the proxy rewrite the Set-Cookie headers. With Apache, for example:

ProxyPass /mirror/foo/ http://backend.example.com:8080/
ProxyPassReverse /mirror/foo/ http://backend.example.com:8080/
ProxyPassReverseCookieDomain backend.example.com public.example.com
ProxyPassReverseCookiePath / /mirror/foo/

See also

<https://httpd.apache.org/docs/2.4/mod/mod_proxy.html>, $cfg['PmaAbsoluteUri']

1.41 When I view a database and ask to see its privileges, I get an error about an unknown column.

The MySQL server’s privilege tables are not up to date, you need to run the mysql_upgrade command on the server.

1.42 How can I prevent robots from accessing BetterMyAdmin?

BetterMyAdmin sends an X-Robots-Tag: noindex, nofollow header with every response, which keeps well-behaved search engines from indexing it. That does not stop other robots: to keep them away, do not expose BetterMyAdmin to the internet at all (it listens on 127.0.0.1 by default, see $cfg['Listen']['host']), restrict access by IP address in your firewall or reverse proxy, or require an authentication in front of it (see Securing your BetterMyAdmin installation).

1.43 Why can’t I display the structure of my table containing hundreds of columns?

BetterMyAdmin does not run on PHP, so PHP’s memory_limit does not apply. If a table with very many columns is slow to display, it is the browser that has to render the page.

1.44 How can I reduce the installed size of phpMyAdmin on disk?

BetterMyAdmin is not installed from PHP files and composer packages: it is distributed as a Docker image, or built from a checkout with pnpm, and its features are not separate files you can remove. The Docker image is the smallest way to run it.

1.45 I get an error message about unknown authentication method caching_sha2_password when trying to log in

This error comes from PHP’s mysqli before PHP 7.4. BetterMyAdmin does not run on PHP: its MySQL driver supports the caching_sha2_password authentication method of MySQL 8.0 and newer, so this error does not occur and no workaround is needed. If you changed an account to mysql_native_password for phpMyAdmin, it keeps working with BetterMyAdmin.

See also

<https://github.com/phpmyadmin/phpmyadmin/issues/14220>

1.46 Missing HTTP_HOST variable when using nginx with HTTP/3

BetterMyAdmin reads the host name from the Host header of each request (the HTTP_HOST variable in phpMyAdmin’s messages). When the header is missing, for example behind nginx with HTTP/3 enabled, several things break:

  • Two-factor authentication won’t work

  • Exported settings have no hostname in the filename (e.g., BetterMyAdmin-config-.json)

  • The hostname is missing from the page title (empty @HTTP_HOST@)

To fix this issue, make the reverse proxy pass the host on; with nginx, add the following line to the location block that proxies to BetterMyAdmin:

proxy_set_header Host $host;

See also

<https://github.com/nginx/nginx/issues/455>, <https://trac.nginx.org/nginx/ticket/2281>

Configuration

2.1 The error message “Warning: Cannot add header information - headers already sent by …” is displayed, what’s the problem?

This is a PHP warning. BetterMyAdmin’s configuration file is data (JSON, YAML) or a JavaScript module, not PHP code, so it cannot occur. A configuration file that cannot be read stops the server at start with a message saying why.

2.2 BetterMyAdmin can’t connect to MySQL. What’s wrong?

Either the connection settings or your username/password is wrong. Check $cfg['Servers'][$i]['host'] and $cfg['Servers'][$i]['port'] (or PMA_HOST and PMA_PORT) and that the MySQL server accepts connections from the host BetterMyAdmin runs on. In a Docker container, localhost is the container itself, not the machine running it: use the database container’s name (for example db) or the machine’s address instead. The error message shown on the login page says what failed (unless $cfg['Servers'][$i]['hide_connection_errors'] is set).

2.3 The error message “Warning: MySQL Connection Failed: Can’t connect to local MySQL server through socket ‘/tmp/mysql.sock’ (111) …” is displayed. What can I do?

The error message can also be: Error #2002 - The server is not responding (or the local MySQL server’s socket is not correctly configured).

First, you need to determine what socket is being used by MySQL. To do this, connect to your server and go to the MySQL bin directory. In this directory there should be a file named mysqladmin. Type ./mysqladmin variables, and this should give you a bunch of info about your MySQL server, including the socket (/tmp/mysql.sock, for example). You can also ask your ISP for the connection info or, if you’re hosting your own, connect from the ‘mysql’ command-line client and type ‘status’ to get the connection type and socket or port number.

Then, you need to tell BetterMyAdmin to use this socket with $cfg['Servers'][$i]['socket'] (or PMA_SOCKET with Docker). Please also make sure that the permissions of this file allow it to be read by the user running BetterMyAdmin; with Docker, the socket’s directory has to be mounted into the container. On many Linux distributions the socket of MySQL is /var/lib/mysql/mysql.sock or /run/mysqld/mysqld.sock.

Have also a look at the corresponding section of the MySQL documentation.

2.4 Nothing is displayed by my browser when I try to run BetterMyAdmin, what can I do?

Make sure that JavaScript is enabled in your browser: BetterMyAdmin’s interface is a JavaScript application. Then look at the browser’s JavaScript console (see 5.19 I get JavaScript errors in my browser.) and at BetterMyAdmin’s error output. When running from a checkout, make sure the web application has been built (pnpm build) before pnpm start.

2.5 Each time I want to insert or change a row or drop a database or a table, an error 404 (page not found) is displayed or, with HTTP or cookie authentication, I’m asked to log in again. What’s wrong?

If you are running BetterMyAdmin behind a reverse proxy, please set the $cfg['PmaAbsoluteUri'] directive (and, for a path other than /, $cfg['Listen']['basePath']) in the BetterMyAdmin configuration file to match your setup, and make sure the proxy passes the Host header and cookies through.

2.6 I get an “Access denied for user: ‘root@localhost’ (Using password: YES)”-error when trying to access a MySQL-Server on a host which is port-forwarded for my localhost.

When you are using a port on your localhost, which you redirect via port-forwarding to another host, MySQL is not resolving the localhost as expected. Erik Wasser explains: The solution is: if your host is “localhost” MySQL (the command line tool mysql as well) always tries to use the socket connection for speeding up things. And that doesn’t work in this configuration with port forwarding. If you enter “127.0.0.1” as hostname, everything is right and MySQL uses the TCP connection.

2.9 Seeing an upload progress bar

2.10 How to generate a string of random bytes

One way to generate a random string suitable for cryptographic use is the crypto module of Node.js, which BetterMyAdmin already needs:

node -e "console.log(require('crypto').randomBytes(24).toString('base64'))"

or, with OpenSSL:

openssl rand -base64 24

Both print 32 characters made of 24 random bytes, something similar to:

sKpL0qkZ3m4J8Yw1n6eVb2rT9cXu5hDa

which can be used in the configuration file, for example for $cfg['blowfish_secret']:

{ "blowfish_secret": "sKpL0qkZ3m4J8Yw1n6eVb2rT9cXu5hDa" }

Without a blowfish_secret, BetterMyAdmin generates one on the first start and keeps it in $cfg['DataDir']. phpMyAdmin’s sodium_hex2bin() form is PHP code and cannot be used in a configuration file.

3.1 When using HTTP authentication, a user who logged out can not log in again in with the same nick.

This is related to the authentication mechanism (protocol) used by BetterMyAdmin. To bypass this problem: just close all the opened browser windows and then go back to BetterMyAdmin. You should be able to log in again.

3.2 When dumping a large table in compressed mode, I get a memory limit error or a time limit error.

This is a PHP limitation that BetterMyAdmin does not have: it streams every export, compressed or not, in bounded memory, and an export has no time limit ($cfg['ExecTimeLimit'] applies to imports only). With $cfg['CompressOnFly'], gzip output is compressed in chunks.

3.4 I am unable to import dumps I created with the mysqldump tool bundled with the MySQL server distribution.

The problem is that older versions of mysqldump created invalid comments like this:

-- MySQL dump 8.22
--
-- Host: localhost Database: database
---------------------------------------------------------
-- Server version 3.23.54

The invalid part of the code is the horizontal line made of dashes that appears once in every dump created with mysqldump. If you want to run your dump you have to turn it into valid MySQL. This means, you have to add a whitespace after the first two dashes of the line or add a # before it: -- ------------------------------------------------------- or #---------------------------------------------------------

4.2 What’s the preferred way of making BetterMyAdmin secure against evil access?

This depends on your system. If you’re running a server which cannot be accessed by other people, keeping BetterMyAdmin on 127.0.0.1 (the default of $cfg['Listen']['host']) or behind a reverse proxy that asks for a password may be enough. If other people can reach it, you should use BetterMyAdmin’s HTTP or cookie authentication features.

Suggestions:

  • Your configuration file should be readable only by the user running BetterMyAdmin and by you (for example chmod 640), and never world writable (see $cfg['CheckConfigurationPermissions']).

  • Keep $cfg['DataDir'] private (BetterMyAdmin creates it with mode 0700).

  • Serve BetterMyAdmin over HTTPS and follow the recommendations in Securing your BetterMyAdmin installation.

4.3 I get errors about not being able to include a file in /lang or in /libraries.

BetterMyAdmin does not run on PHP, so PHP’s include_path and open_basedir do not apply, and the directories named in the question do not exist.

4.4 BetterMyAdmin always gives “Access denied” when using HTTP authentication.

This could happen for several reasons:

  • $cfg['Servers'][$i]['controluser'] and/or $cfg['Servers'][$i]['controlpass'] are wrong.

  • The username/password you specify in the login dialog are invalid.

  • You have already setup another HTTP authentication in front of BetterMyAdmin, for example in a reverse proxy. Its credentials are sent in the same header and would interfere with BetterMyAdmin’s authentication, so remove it (or use cookie authentication).

  • Failed logins are rate limited: after too many of them, the account is locked out for a while (see $cfg['LoginRateLimit']).

4.5 Is it possible to let users create their own databases?

Starting with 2.2.5, in the user management page, you can enter a wildcard database name for a user (for example “joe%”), and put the privileges you want. For example, adding SELECT, INSERT, UPDATE, DELETE, CREATE, DROP, INDEX, ALTER would let a user create/manage their database(s).

4.6 How can I use the Host-based authentication additions?

If you have existing rules from an old .htaccess file, you can take them and add a username between the 'deny'/'allow' and 'from' strings. Using the username wildcard of '%' would be a major benefit here if your installation is suited to using it. Then you can just add those updated lines into the $cfg['Servers'][$i]['AllowDeny']['rules'] array.

If you want a pre-made sample, you can try this fragment. It stops the ‘root’ user from logging in from any networks other than the private network IP blocks.

{
  "Servers": [{
    "AllowDeny": {
      "order": "deny,allow",
      "rules": [
        "deny root from all",
        "allow root from localhost",
        "allow root from 10.0.0.0/8",
        "allow root from 192.168.0.0/16",
        "allow root from 172.16.0.0/12"
      ]
    }
  }]
}

6.6 How can I use the relation table in Query-by-example?

CREATE TABLE REL_countries (
country_code char(1) NOT NULL default '',
description varchar(10) NOT NULL default '',
PRIMARY KEY (country_code)
) ENGINE=MyISAM;

INSERT INTO REL_countries VALUES ('C', 'Canada');

CREATE TABLE REL_persons (
id tinyint(4) NOT NULL auto_increment,
person_name varchar(32) NOT NULL default '',
town_code varchar(5) default '0',
country_code char(1) NOT NULL default '',
PRIMARY KEY (id)
) ENGINE=MyISAM;

INSERT INTO REL_persons VALUES (11, 'Marc', 'S', 'C');
INSERT INTO REL_persons VALUES (15, 'Paul', 'S', 'C');

CREATE TABLE REL_towns (
town_code varchar(5) NOT NULL default '0',
description varchar(30) NOT NULL default '',
PRIMARY KEY (town_code)
) ENGINE=MyISAM;

INSERT INTO REL_towns VALUES ('S', 'Sherbrooke');
INSERT INTO REL_towns VALUES ('M', 'Montréal');

To setup appropriate links and display information:

  • on table “REL_persons” click Structure, then Relation view

  • for “town_code”, choose from dropdowns, “mydb”, “REL_towns”, “town_code” for foreign database, table and column respectively

  • for “country_code”, choose from dropdowns, “mydb”, “REL_countries”, “country_code” for foreign database, table and column respectively

  • on table “REL_towns” click Structure, then Relation view

  • in “Choose column to display”, choose “description”

  • repeat the two previous steps for table “REL_countries”

Then test like this:

  • Click on your db name in the navigation panel

  • Choose “Query”

  • Use tables: persons, towns, countries

  • Click “Update query”

  • In the columns row, choose persons.person_name and click the “Show” tickbox

  • Do the same for towns.description and countries.descriptions in the other 2 columns

  • Click “Update query” and you will see in the query box that the correct joins have been generated

6.12 I want to understand some Export options.

Structure:

  • “Add DROP TABLE” will add a line telling MySQL to drop the table, if it already exists during the import. It does NOT drop the table after your export, it only affects the import file.

  • “If Not Exists” will only create the table if it doesn’t exist. Otherwise, you may get an error if the table name exists but has a different structure.

  • “Add AUTO_INCREMENT value” ensures that AUTO_INCREMENT value (if any) will be included in backup.

  • “Enclose table and column names with backquotes” ensures that column and table names formed with special characters are protected.

  • “Add into comments” includes column comments, relations, and media types set in the pmadb in the dump as SQL comments (/* xxx */).

Data:

  • “Complete inserts” adds the column names on every INSERT command, for better documentation (but resulting file is bigger).

  • “Extended inserts” provides a shorter dump file by using only once the INSERT verb and the table name.

  • “Delayed inserts” are best explained in the MySQL manual - INSERT DELAYED Syntax.

  • “Ignore inserts” treats errors as a warning instead. Again, more info is provided in the MySQL manual - INSERT Syntax, but basically with this selected, invalid values are adjusted and inserted rather than causing the entire statement to fail.

6.37 How can I use Improve Table structure feature?

Improve table structure feature helps to bring the table structure upto Third Normal Form. A wizard is presented to user which asks questions about the elements during the various steps for normalization and a new structure is proposed accordingly to bring the table into the First/Second/Third Normal form. On startup of the wizard, user gets to select upto what normal form they want to normalize the table structure.

Here is an example table which you can use to test all of the three First, Second and Third Normal Form.

CREATE TABLE `VetOffice` (
 `petName` varchar(64) NOT NULL,
 `petBreed` varchar(64) NOT NULL,
 `petType` varchar(64) NOT NULL,
 `petDOB` date NOT NULL,
 `ownerLastName` varchar(64) NOT NULL,
 `ownerFirstName` varchar(64) NOT NULL,
 `ownerPhone1` int(12) NOT NULL,
 `ownerPhone2` int(12) NOT NULL,
 `ownerEmail` varchar(64) NOT NULL,
);

The above table is not in First normal Form as no primary key exists. Primary key is supposed to be (petName,`ownerLastName`,`ownerFirstName`) . If the primary key is chosen as suggested the resultant table won’t be in Second as well as Third Normal form as the following dependencies exists.

(OwnerLastName, OwnerFirstName) -> OwnerEmail
(OwnerLastName, OwnerFirstName) -> OwnerPhone
PetBreed -> PetType

Which says, OwnerEmail depends on OwnerLastName and OwnerFirstName. OwnerPhone depends on OwnerLastName and OwnerFirstName. PetType depends on PetBreed.

6.38 How can I reassign auto-incremented values?

Some users prefer their AUTO_INCREMENT values to be consecutive; this is not always the case after row deletion.

Here are the steps to accomplish this. These are manual steps because they involve a manual verification at one point.

  • Ensure that you have exclusive access to the table to rearrange

  • On your primary key column (i.e. id), remove the AUTO_INCREMENT setting

  • Delete your primary key in Structure > indexes

  • Create a new column future_id as primary key, AUTO_INCREMENT

  • Browse your table and verify that the new increments correspond to what you’re expecting

  • Drop your old id column

  • Rename the future_id column to id

  • Move the new id column via Structure > Move columns

6.39 What is the “Adjust privileges” option when renaming, copying, or moving a database, table, column, or procedure?

When renaming/copying/moving a database/table/column/procedure, MySQL does not adjust the original privileges relating to these objects on its own. By selecting this option, BetterMyAdmin will adjust the privilege table so that users have the same privileges on the new items.

For example: A user ‘bob’@’localhost’ has a ‘SELECT’ privilege on a column named ‘id’. Now, if this column is renamed to ‘id_new’, MySQL, on its own, would not adjust the column privileges to the new column name. BetterMyAdmin can make this adjustment for you automatically.

Notes:

  • While adjusting privileges for a database, the privileges of all database-related elements (tables, columns and procedures) are also adjusted to the database’s new name.

  • Similarly, while adjusting privileges for a table, the privileges of all the columns inside the new table are also adjusted.

  • While adjusting privileges, the user performing the operation must have the following privileges:

    • SELECT, INSERT, UPDATE, DELETE privileges on following tables: mysql.`db`, mysql.`columns_priv`, mysql.`tables_priv`, mysql.`procs_priv`

    • FLUSH privilege (GLOBAL)

Thus, if you want to replicate the database/table/column/procedure as it is while renaming/copying/moving these objects, make sure you have checked this option.

6.41 I get import errors while importing the dumps exported from older MySQL versions (pre-5.7.6) into newer MySQL versions (5.7.7+), but they work fine when imported back on same older versions ?

If you get errors like #1031 - Table storage engine for ‘table_name’ doesn’t have this option while importing the dumps exported from pre-5.7.7 MySQL servers into new MySQL server versions 5.7.7+, it might be because ROW_FORMAT=FIXED is not supported with InnoDB tables. Moreover, the value of innodb_strict_mode would define if this would be reported as a warning or as an error.

Since MySQL version 5.7.9, the default value for innodb_strict_mode is ON and thus would generate an error when such a CREATE TABLE or ALTER TABLE statement is encountered.

There are two ways of preventing such errors while importing:

  • Change the value of innodb_strict_mode to OFF before starting the import and turn it ON after the import is successfully completed.

  • This can be achieved in two ways:

    • Go to ‘Variables’ page and edit the value of innodb_strict_mode

    • Run the query : SET GLOBAL `innodb_strict_mode = ‘[value]’`

After the import is done, it is suggested that the value of innodb_strict_mode should be reset to the original value.

8.1 Where can I get information about the security alerts issued for BetterMyAdmin?

BetterMyAdmin’s security fixes are announced in its releases and its changelog. phpMyAdmin’s announcements (<https://www.phpmyadmin.net/security/>) concern phpMyAdmin’s code; one that describes a behaviour BetterMyAdmin shares may concern it too.

8.2 How can I protect BetterMyAdmin against brute force attacks?

BetterMyAdmin limits failed logins by default: five failures of one (IP address, username) pair within 15 minutes lock that pair out for 5 minutes ($cfg['LoginRateLimit']). You can additionally enable a captcha ($cfg['CaptchaLoginPublicKey']).

Authentication attempts are logged ($cfg['AuthLog'], with $cfg['AuthLogSuccess'] for successful ones), to the server’s error output or to a file, in phpMyAdmin’s format. The logged statuses are ok (user is logged in), server-denied (database server denied user login), allow-denied (user denied by allow/deny rules), root-denied (root is denied in configuration), empty-denied (empty password is denied) and no-activity (automatically logged out due to inactivity). You can then use any log analyzing tools, such as fail2ban, to detect possible break-in attempts.

phpMyAdmin’s userID and userStatus Apache environment variables do not exist in BetterMyAdmin, which does not run in Apache.

8.3 Why are there path disclosures when directly loading certain files?

This is a PHP configuration problem (display_errors) that does not apply to BetterMyAdmin: it does not run on PHP, and its error messages to the browser never include stack traces or file paths (the details go to the server’s error output).

8.4 CSV files exported from BetterMyAdmin could allow a formula injection attack.

It is possible to generate a CSV file that, when imported to a spreadsheet program such as Microsoft Excel, could potentially allow the execution of arbitrary commands.

The CSV files generated by phpMyAdmin could potentially contain text that would be interpreted by a spreadsheet program as a formula, but the phpMyAdmin team does not believe escaping those fields is the proper behavior. There is no means to properly escape and differentiate between a desired text output and a formula that should be escaped, and CSV is a text format where function definitions should not be interpreted anyway. They feel it is the responsibility of the spreadsheet program to properly parse and sanitize such data on input instead.

Google also has a similar view.

BetterMyAdmin produces the same files by default, and offers an option for those who prefer escaping: with $cfg['Export']['csv_escape_formulas'], cells starting with =, +, - or @ are escaped in CSV and CSV for MS Excel exports.
