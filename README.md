# BetterMyAdmin

A feature-for-feature rebuild of [phpMyAdmin](https://github.com/phpmyadmin/phpmyadmin) in TypeScript and React with a modern UI, specified against phpMyAdmin 6.0.0-dev commit `e3e877e8`.

Status: documentation and specification phase. No application code yet.

Start with [docs/README.md](docs/README.md), then [docs/00-vision-and-principles.md](docs/00-vision-and-principles.md) and the [roadmap](docs/architecture/13-roadmap-and-milestones.md).
